# PnP Simple 1

Separate from original Sweep 2.4.18. Uses official OpenCV 4.13.0 solvePnP EPnP initialization and ITERATIVE refinement, solving rotation and XYZ together from fixed doll wrist/base-knuckle coordinates and image landmarks. Two seeds (previous solution and fresh EPnP) are refined; near-equal fits prefer temporal translation continuity. Fixed rigid palm points do not change with finger curl. Finger articulation uses the existing constrained rig and estimated relative MediaPipe Z. This is not a full articulated nonlinear optimizer over all finger angles.

Replaces active size-to-root-distance and subsequent XY-fit steps. Rejected fits hold the prior valid pose; initial placement is provisional until a valid fit. Only valid PnP observations enter calibration. Camera focal length still derives from the existing display projection; no measured lens calibration or distortion correction is assumed. PnP can remain ambiguous or biased by landmark/model mismatch.

Keeps the five-second preparation and eight-second one-way front-to-neck sweep, joint hand/bust scales, surface contact and optional collision controls. Use saved sweep calibration toggles its application. Optional camera-to-shoulders distance defaults off at 50 cm and uses the straight-line camera-to-model shoulder midpoint distance measured at the finish. This applies one common frozen scale to both hands and bust, preserving image projection and contact. It is not another live depth blend. Missing shoulder observations leave the original sweep scale and report that a recapture is needed.

Verified in the browser with 144 synthetic actual-doll poses spanning left/right, sideways translations, rotation, portrait/landscape and 0.3–1.2 model-metre depths. No failures, maximum ideal depth error below 1e-7 mm. Changing distal finger landmarks did not change depth. Real sample image produced a 1.6 px palm fit. These are implementation tests, not proof of accurate live phone tracking. Calibration reference tests cover contact, projection, distance, toggling and no accumulated scaling.
