# Sweep 2.4.7 comparison page

Restored from Git commit `d58c086` (Use sweep-referenced palm size with perspective rotation correction) into its own directory. The depth, finger, capture and head algorithms are unchanged from that snapshot. Only navigation/title, browser storage key names and the sample-image path differ. The historical cheek sample was not tracked in Git; Try sample image uses the existing shared count5.png fixture. The current `hand-touch-calibration/` directory remains untouched.

Open `./?v=touch2.4.7` for the original default mode. Its original **Use saved sweep reference** button remains available; `./?v=touch2.4.7&preset=sweep` loads that historical numerical reference directly. Calibration and settings are not transferred from 2.4.10. This is a historical comparison, retaining the older estimator's limitations.
