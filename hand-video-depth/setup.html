Video Depth 2 · PC engine

The original sweep and MediaPipe tracking run as before. This separate experiment runs the official Metric Video Depth Anything Small streaming model on your PC. GitHub Pages cannot run its Python model.

  1. On this PC the engine is already installed. From the rps-hand checkout, run powershell -File tools/start-vda.ps1. Keep it running while testing.
  2. On a different Windows PC, install Python and Git, obtain the repository, and run powershell -File tools/setup-vda.ps1 once before starting. The first installation downloads PyTorch and model weights.
  3. Open Video Depth 2 on the same PC. Click Connect iPhone / phone · QR on this receiving page. Scan the new QR on your iPhone, allow camera access there, and tap Start camera. A connection in another sweep tab is not shared automatically. The QR always opens the public HTTPS phone sender, including when this receiver is local. Use PC webcam is a separate optional button. The phone sends video to the PC.
  4. Click Start depth map. Allow local-network access if your browser asks. Preview does not change hand placement.
  5. Record the usual sweep. Optionally enable Use depth map to help hand depth. Each hand's first reliable sample anchors its map distance to its current sweep position. Toggling this off and on clears those map references. Resetting or recording a sweep clears them too.

The engine binds only to 127.0.0.1:8788. Camera frames are processed locally and are not saved by the engine. Supported page origins are GitHub Pages and the local port 8776 test server. If your browser blocks access from the public page, open the direct PC preview. The same engine serves this identical page, so no second server or cross-site permission is needed.

GPU and speed

This PC has a tested AMD RX 6600 DirectML runtime. Choose GPU or CPU on the page. Fast uses 168 input pixels, Balanced 224, Detailed 336. Lower resolution trades spatial detail for speed. The first GPU frame includes initialization. Requests run one at a time without a fixed 200 ms pause. To install GPU support on another Windows PC, run tools/setup-vda-gpu.ps1, then tools/start-vda.ps1. The small compatibility patch skips an unused autocast context during FP32 inference; model weights and temporal calculations remain unchanged.

What this experiment measures

It predicts a depth map, then samples a small region bounded by the wrist and base knuckles. The values labelled metres are learned estimates, not TrueDepth sensor measurements. The optional correction offers 0–100% map contribution, initially 25% map and 75% palm after anchoring the map reference. Maps older than 2.5 seconds, moved palm regions and inconsistent regions are ignored. At 100% contribution, hold the last map depth; below 100%, fall back to palm depth. Calibration pauses map correction; the sweep's rear boundary still applies.

Depth updates are asynchronous and slower than hand tracking. The panel reports actual inference time and completed map updates per second. Hand occlusion, rapid motion and fine fingertip contact can remain inaccurate. Preview colours are normalized separately for each frame. This is not a guarantee of improved tracking.

Model: official Video Depth Anything, tested revision 4f5ae23, CPU or DirectML GPU, FP32, adjustable 168/224/336 input size, experimental streaming implementation. Original model/code licenses apply; weights are downloaded separately.
