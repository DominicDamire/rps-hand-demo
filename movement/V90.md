# V90: fixed hand attachments, checked in Blender

The v80 mesh and measured joint hierarchy remain. The driver no longer moves knuckle pivots or scales the palm/fingers during calibration. It follows each tracked segment using a rotation in its parent's frame, retaining palm orientation instead of giving each part an independent world-space twist. The original connected assembly now stays at its authored attachment centers. Recenter restores the original offsets and unit scales.

## Verification

- 81 movement unit tests pass.
- The browser hand check asserts fixed joint offsets and unit hand/finger scales as well as all 30 tracked segment directions on both hands. Open, curl, spread, pinch, isolated index, reacquisition, head rotation and recalibration checks pass. The synthetic curl fixture was corrected to bend about the palm's transverse axis; the previous fixture rotated in the palm plane.
- Actual browser joint matrices were exported to `blender-check/verified-poses.json`. Five synthetic poses and four MediaPipe photo poses were imported into Blender 5.2 using `tools/doll/verify_hand_attachments.py`. This script rebuilds the same attachment tree and applies the exported matrices directly, without substituting a separate Blender pose solver.
- Blender produced 18 renders (palm and oblique views of nine poses), plus `hand-attachments.blend` with pose keys at frames 1,21,41,...,161. Attachment translation error is below 0.0001 mm and scale error below 0.000001 in these snapshots. Open-hand, curl, real fist and peace-sign renders were visually inspected.
- One photo (`raised_fist.jpg`) was not detected by MediaPipe. Camera/network latency and arm-reach limits are unchanged. This fix addresses the drifting attachment points and segment rotations; mechanical seams in the original doll mesh remain.

Reproduce from the repository root:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' -b --python tools/doll/verify_hand_attachments.py -- docs/doll.glb docs/movement/blender-check/verified-poses.json docs/movement/blender-check
```

Open `movement/blender-check/` for the rendered evidence and Blender download. Open `movement/hand-check.html?v=90` for the interactive fixture and photo tracker tests.
