## Historical initial-v89 notes (superseded where noted above)

# Movement v89

Built on v88 (`02efef6`), using v80 (`8b9c082`) hand placement and per-phalanx direction retargeting. Compared with v76 (`3ecf4dd`). The previous main branch had been rolled back to v76; the v89 commit also restores the intervening v88 features and optimized doll asset.

## Hand movement

`hand-model.mjs` retains the v80 landmark-to-world/first-person placement. `doll-hand.mjs` contains the v80 palm frame, knuckle placement and independent segment-direction driver. Every finger has three independently aimed joints. This replaces v88's fixed-X-axis hinge approximation, which misassigned bend angles and inferred the final segment from the preceding joint. Fingers are driven by default; an old `fingers=0` URL no longer disables them.

Calibration caches belong to each doll instance. Segment lengths, rather than the distance across a folded finger, determine scale; calibrating a fist does not shrink the fingers. Calibrate restores finger scales and knuckle positions. The v88 48-part model remains, avoiding the older model's extra draw calls. Wrist IK and v88 head/arm visibility behavior remain, with hidden-arm and stale-left-hand fixes.

## Responsiveness

- v76, v80 and v88 use the same hand tracker. v76 already runs face/hand workers independently, without queuing a second frame while a worker is busy; v89 preserves that scheduling.
- Hidden skinned hand meshes no longer run skin deformation or remain in the scene tree. The doll, gun and joystick still receive the landmark points.
- Joint rotations use already refreshed parent matrices. The root/spine and affected chains are refreshed explicitly; only one full doll traversal remains. Moving the head/heading is covered by the regression fixture.
- 3D rendering is capped at 60 Hz without capping input/capture callbacks. The clock is tested at 60/75/90/120/144/165 Hz and after long pauses.
- A visible mirror refreshes at up to 30 Hz nearby, 20 Hz at medium range and 10 Hz far away, independent of display refresh. V88's far reflection updated only every 16 rendered frames by default on desktop. Explicit `mirror=` overrides remain available.
- Face diagnostics update at 10 Hz, hand diagnostics at most 15 Hz, and unchanged body-status text is not rewritten every frame.
- Restored a tracker error handler accidentally swallowed by a v88 line comment. Phone connection URLs and movement imports carry v89 cache keys. The page banner and title identify v89.

These changes reduce unnecessary rendering work and mirror delay; they do not promise zero camera/network/inference latency on every phone.

## Validation

Run all movement tests in PowerShell:

```powershell
$tests = Get-ChildItem docs/movement -Filter '*.test.mjs'
node --test $tests.FullName
```

Open `movement/hand-check.html` for repeatable open, fist, spread, pinch and isolated-index poses on both hands. It measures all 30 segment directions and both wrists, checks loss/reacquisition, head rotation and calibration while folded. The check passes below 0.01 degrees direction error and 5 mm wrist error on these synthetic reachable targets. Synthetic poses are a rig regression check, not proof of camera accuracy.

For comparison, create detached sibling worktrees named `baseline-v76`, `baseline-v80`, `baseline-v88` at the commits above. Serve their parent folder together with this checkout, then add `?compare=1` to the check URL. Each body rig receives the same synthetic landmarks. The microbenchmark performs 100 warmup and 1,000 measured updates, without rendering the map or running inference. Example run on the development machine:

| Version | Worst fist segment error | Matrix updates / body frame | Mean body update |
| --- | ---: | ---: | ---: |
| v76 | <0.0001 degrees | 912 | 0.1254 ms |
| v80 | <0.0001 degrees | 959 | 0.1292 ms |
| v88 | 170.8706 degrees | 413 | 0.0633 ms |
| v89 | <0.0001 degrees | 210 | 0.0430 ms |

Timings vary with browser/machine load; these are CPU rig costs, not end-to-end tracking latency. V89 performs about 77% fewer matrix updates than v76 and 49% fewer than v88 in this fixture.

The **Test tracking photos** button additionally runs the actual MediaPipe worker on repository reference photos and passes the detected points through the v80 hand wrapper into the doll. Open hand, user fist, peace sign and thumbs-up were detected, with <0.0001 degree segment-direction error. `raised_fist.jpg` was not detected after four attempts. The pose tracker remains unchanged. Some detected photo wrists lie beyond the doll's fixed arm reach (measured residuals up to 144 mm), so arm IK still clamps those targets. No new arm stretching was introduced.

The full game was loaded locally, its map/model/gun loaded, and its forward movement demo exercised. Final live-page verification checks the deployed v89 module, banner and hand regression page. Live camera and phone-network latency require testing on the player's actual device.
